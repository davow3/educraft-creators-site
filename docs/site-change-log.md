# Site Change Log

EduCraft Creators site の公開前メンテナンス履歴です。
外部に出ても困らない範囲の修正内容だけを残します。

## 2026-09-11

- 「さんすうクエスト マスターズ」のクローズドテスト完了と、Google Play製品版アクセス申請中の状況を掲載
- 公式YouTube Shortsの紹介カードを追加し、ゲーム画面から動画へ移動できる導線を整備
- さんすうクエスト、さんすうディフェンダー、さんすうファイトの紹介アイコンを現行の起動アイコンへ更新
- ローカル確認用MP4を公開リポジトリへ含めず、YouTube公開版を案内する構成に統一

## 2026-09-07

- DB Bottleneck Analyzer v0.4.0の14日間無料試用インストーラーを製品ページから直接ダウンロード可能にした
- ライセンス条件を「診断端末1台、同一組織内の利用人数・接続先DB数は無制限」へ確定
- 日本国内向けStripe Buy Buttonを追加し、日本国外向けPolarは準備中のまま分離
- 購入後は端末申請ファイルをメール送付し、2営業日以内を目安に署名済みオフラインライセンスを手動発行する導線を追加
- 販売情報、利用規約、プライバシー、返金方針を14日試用・端末1台・手動ライセンス発行の現行仕様へ更新
- 現在のWindows配布物が未署名であることとSHA-256をダウンロード導線に明記

## 2026-09-06

- 製品名を「DB Bottleneck Analyzer」へ変更し、専用URLを`/db-bottleneck-analyzer/`へ移行
- 旧`/pgscope/`から新URLへの案内ページを追加
- Stripe審査向けに製品説明、予定価格、提供方法、および販売・返金・プライバシー・利用規約ページを追加
- 販売準備中は製品ページを検索対象外とし、学習アプリ側からリンクしない構成を維持
- 学習アプリ側からDB Bottleneck AnalyzerのリンクとToolsセクションを削除し、製品ページを独立した入口として分離
- PostgreSQL安全診断・比較ツール「DB Bottleneck Analyzer」の5言語商品ページを追加
- 表示言語と購入地域を分離し、日本国内はStripe、日本国外はPolarへ案内する購入導線の土台を追加
- 1ライセンスで同一購入者の診断端末3台まで、利用人数・接続DB数は制限しない方針と地域別価格案を追加
- 決済リンク未設定時は購入できない安全な「販売準備中」状態とした
- フッターの個人名表記を削除

## 2026-09-05

- 「さんすうファイト」のコード不要の再戦、匿名ランダム対戦、匿名ランキングを紹介文へ反映
- ランダム対戦で保存する匿名ID・対戦数・勝数・勝率・レーティングと、アプリ内からの削除方法をプライバシーポリシーへ追記
- 実名、自由入力、チャット、連絡先、広告ID、端末IDを送信しないことと、対戦ルーム・待機情報の保存期間を明記

## 2026-09-01

- 「さんすうファイト」の友だち限定オンライン対戦で一時的に処理する対戦情報をプライバシーポリシーへ追記
- 通信中継にCloudflare Workers / Durable Objectsを使用すること、プレイヤー名・チャット・広告IDを送信しないこと、ルームを短時間で削除することを明記
- Cloudflareのプライバシーポリシーへのリンクを追加

## 2026-08-23

- 公開準備中のアプリ一覧に「さんすうファイト」を追加
- 公開準備中のアプリ一覧に「カバのねごとスイカ」を追加
- 各アプリで実際に使用している起動アイコンを紹介画像として追加
- プライバシーポリシーの対象アプリを5本へ更新し、カバの思い出カスタムで選択する写真は端末内だけで利用することを追記
- Google Play Billingを使うアプリには購入処理用の通信権限が含まれることを、プライバシーポリシーへ明記
- カバの思い出カスタムに独り言の変更を追加し、紹介文とプライバシーポリシーへ反映
