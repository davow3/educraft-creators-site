# Site Change Log

EduCraft Creators site の公開前メンテナンス履歴です。
外部に出ても困らない範囲の修正内容だけを残します。

## 2026-09-01

- 「さんすうファイト」の友だち限定オンライン対戦で一時的に処理する対戦情報をプライバシーポリシーへ追記
- 通信中継にCloudflare Workers / Durable Objectsを使用すること、プレイヤー名・チャット・広告IDを送信しないこと、ルームを短時間で削除することを明記
- Cloudflareのプライバシーポリシーへのリンクを追加

## 2026-08-23

- 公開準備中のアプリ一覧に「さんすうファイト」を追加
- 公開準備中のアプリ一覧に「カバのねごとスイカ」を追加
- 各アプリで実際に使用している起動アイコンを紹介画像として追加
- プライバシーポリシーの対象アプリを5本へ更新し、カバの思い出カスタムで選択する写真は端末内だけで利用することを追記
- Google Play Billingを使うアプリには購入処理用の通信権限が含まれることを、プライバシーポリシーへ明記
- カバの思い出カスタムに独り言の変更を追加し、紹介文とプライバシーポリシーへ反映

## 2026-08-11

- サイト資源を独立した `educraft-creators-site` リポジトリへ移動
- ブラウザタブの favicon をコック顔に変更
- 「つくっている人たち」の yuichi 画像を青線コックに戻した
- ヒーロー画像は色付きコックのまま維持
- About に大きく出していた事業情報を削除し、フッターに控えめ表示へ変更
- アプリ一覧のアイコンを最新素材に差し替え
- 屋号 `EduCraft Studio`、制作ブランド `EduCraft Creators`、運営者名をフッターに整理
