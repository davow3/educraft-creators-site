DBA FIRST RESPONSE

最初に見るべき順番を崩さない

結果の羅列ではなく、影響が大きい候補から安全な次の確認へ進みます。

01

優先対応を確認

ロック、長時間トランザクション、SQL、テーブルの候補を影響順に確認します。

02

根拠を掘り下げる

SQL統計、関連テーブル候補、dead tuples、実行元の観測結果を確認します。

03

改善前後を比較

同等条件のスナップショットを比較し、SQL・テーブル単位で変化を確認します。

SAFE BY DESIGN

観測はする。変更はしない。

本番利用ではObserveとRecommendに限定し、変更や負荷試験は検証環境へ分離します。

DB Bottleneck Analyzerが行うこと

  • 統計ビューとシステムカタログの読み取り
  • 最大1接続・直列取得・行数制限
  • SQL 1.5秒、ロック待ち0.25秒で中止
  • 外部キー定義からE-R構造を表示

DB Bottleneck Analyzerが行わないこと

  • VACUUMや設定変更の自動実行
  • EXPLAIN ANALYZEの本番実行
  • セッション終了や拡張機能追加
  • テーブルの業務データ取得

保持とSQL表示を選べる

  • 分析結果をメモリだけに保持
  • 必要時だけOS資格情報ストアで暗号化保存
  • SQL本文は取得しない／概要／全文から選択
  • パスワードをレポートへ含めない

負荷ゼロを保証するものではありません。最初は検証環境または低負荷時間帯で確認してください。
